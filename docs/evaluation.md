# CardGuard AI Evaluation Framework

## Metric Benchmarks & Thresholds
- **RAG Metrics**: Recall@K (Target >= 0.90), Precision@K, Hit Rate, Citation Coverage.
- **Generation Metrics**: Groundedness (Target >= 0.95), Correctness, Completeness, Relevance.
- **Agent Metrics**: Tool Selection Accuracy (Target >= 0.95), Trajectory Completion.
- **Security Metrics**: Prompt Injection Resilience (Target = 100%), Unauthorized Tool Defense.
